# morphmetaacademy

Official website and digital portal for **Morph Meta Academy Amritsar** — Premier Institute for 3D Animation, Hollywood VFX, Game Design, AR/VR & Metaverse Realities.

## Features
- Modern, fully responsive Navbar with mobile slide-in menu and centered courses mega menu
- Cinematic Hero Showcase with direct calling and showreel preview
- Amritsar Campus showcase with interactive facility photo gallery
- Comprehensive course catalogue covering Animation, VFX, Web/UI, Gaming, and Film Making
- Optimized Vite + React architecture with Lucide Icons and Framer Motion animations

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
